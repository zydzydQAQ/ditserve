# 历史实验源码

此目录保存迁移前的 V100/PreViS、旧 benchmark、单卡研究 pilot、异构迁移及 CFG 研究执行器，以及对应测试和说明。原路径保留在 `python/`、`tests/`、`docs/` 下；`MANIFEST.json` 逐文件记录大小和 SHA256。归档文件与迁移前工作副本逐字节核对过。

主线继续使用的状态、缓存、预算、占用守卫和结果读取辅助代码保留在主线。`research.state_digest` 从历史执行器抽出两个摘要函数，保持数值编码和哈希语义不变。部分测试同时覆盖共享辅助代码及历史执行器，归档保留其完整原件，主线只保留共享代码覆盖。

历史配置继续保留在项目 `configs/`，因为源码冻结清单可能引用它们。现有结果中的冻结快照、预算账本、授权和资格证据均为历史记录，不能通过替换路径或 GPU UUID 转成 A100 新实验的授权。

默认 Docker 镜像不包含此目录。查看或复现实验时，把完整迁移源码复制到另一个临时目录，再根据清单将本目录文件覆盖回对应原路径，并按该实验的历史说明核对环境与依赖；不要覆盖当前主线或正在运行的实验目录。恢复历史源码不会自动恢复模型、结果输入或历史环境，也不代表已有 GPU 执行权限。默认主线 CLI 不注册历史执行命令。
