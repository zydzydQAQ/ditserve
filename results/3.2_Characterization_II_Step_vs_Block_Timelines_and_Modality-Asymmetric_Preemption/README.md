## 1. 核心实测结论（Insight 3）

1. **跨模态执行量子悬殊（Fig. 5a）**：在紧图像截止期（$\kappa=1.25\times$，`sd35-512` 排队松弛预算仅 **$B = 429.7\text{ ms}$**）下，视频 `CFG2` 单步长达 **1.54–8.15 s**（超出 $B$ **3.6×–19.0×**），且 **79.0%–89.4%** 的有队列 GPU 空闲等待来自 `3.59–6.91 s` 的 Rank-0 3D-VAE 解码，`first-fit` 放置打碎 `{2k, 2k+1}` 对偶对导致视频 SAR 跌落 **24.7 pp**。
2. **视频支持且必须采用单 Block 安全点抢占（Fig. 5b）**：视频单 Block 耗时 **45–94 ms**（$\ll B$），退出 Block $b-1$ 时自动释放 `4.45–12.48 GiB` 临时工作区且无在途集合通信，仅驻留 **220–480 MiB/GPU**（**0 B PCIe swap**）。实测暂停延迟 **63.75 ms**，将紧预算图像等待从 `1,706.3 ms` 降至 **56.6 ms**（缩短 **26.77×**），E2E 从 `3,434.9 ms` (`0% SAR`) 降至 **1,806.1 ms**（**`1.902×` 提速，`100% SAR`**），624/624 视频恢复后 SHA256 **100% 逐位一致**，无抢占检查开销仅 **`-0.38% ~ +0.24%`**。
3. **图像整步已小于松弛预算，Block 级抢占反而有害**：图像整步（24 blocks）仅需 **59.2–221.4 ms**（低于 $B$ 达 `1.9×–7.3×`），而单 MM-DiT Block 仅 **2.5–9.1 ms**，`0.60–1.62 ms` 同步停顿会引入 **24%–65%** 额外开销、双流状态同时突变且破坏步边界 `cu_seqlens` 连续批处理打包。
