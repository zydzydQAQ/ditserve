## 1. 核心实测结论（Insight 4）

1. **跨模态同驻 HBM 显存墙（Table 2）**：在 40 GB A100（可用 `39.50 GiB`）上同时驻留 `UMT5-XXL` (`10.58 GiB`) 与 `T5-XXL` (`8.87 GiB`) 会占去 **19.45 GiB/GPU**，叠加激活与缓存悬垂 (`0.58–2.53 GiB`) 后峰值达 **40.1–54.0 GiB（100% OOM）**；反应式权重换入换出 (`S1`) 每次停顿 **2.74–3.91 s**；朴素 512-token CPU 编码 (`S2/S3`) 在 17–24 token 提示词上浪费 **95.9%** 自注意力算力。
2. **S4 编码器解耦 + UMT5 无损截断 + T5-XXL 正负分离缓存**：每卡节省 **19.45 GiB**（8 卡共省 **155.60 GiB**，**0 OOM**）；视频 UMT5 有效截断 CPU 提速 **5.87×–8.08×**（缓存命中 **15.58×**）；图像 CPU `T5-XXL` 正负条件分离缓存（`8` 线程 + `/dev/shm` 跨进程零拷贝领用）将冷启动编码从 `54.79 s` 压至 **`13.84 s`（`3.96×`）**、热命中异步 H2D 仅 **`0.68 ms`（`80,927×`，`max|Δ| = 0.0`）**。
3. **单核 `flash_attn_varlen` 无填充打包 + 跨分辨率防负优化门禁 + FlashPS 三流流水**：异构 $512^2/1024^2$ 单核融合 `flash_attn_varlen`（`vllm_flash_attn`）将单步从 2D Padding 的 `444.88 ms` 压至 **`260.09 ms`（`1.710×`）**，$2\times 512^2 + 1\times 1024^2$ 达 **`2.000×–2.020×`**；针对极端跨度 $512^2 + 1440^2$（`8.85×` 单步膨胀，`1.71 s -> 15.13 s` 负优化），控制面膨胀门禁（`max_step_dilation=4.5`）精准拦截并回退串行（`1.75 s`）；FlashPS 三流流水（`encode + compute + vae`）实现 **`5.123×`** 端到端加速并消除 **`172.45 ms`** 步末退役阻塞。
