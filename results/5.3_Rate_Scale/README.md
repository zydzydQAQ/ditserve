# §5.3 Rate Scale

- **对应论文小节**：`body/05-evaluation.tex` — `\subsection{Rate Scale}`
- **对应论文图表**：`Figure 9` (`fig_eval_rate_scale.pdf`)、`Figure 10` (`fig_eval_rate_p95.pdf`)
- **固定参数**：8× A100-PCIE-40GB，$v = 0.5$，$\kappa = 1.5\times$，扫描到达率 $R \in \{8, 12, 16, 20, 24, 28, 32, 36\}\text{ req/min}$（对应系统容量 $R_0 = 7.55\text{ req/min}$ 的 $1.06\times$ 至 $4.77\times$ 过载，每点 $N=100$ 请求）
- **对比策略（6 策略）**：`xDiT`、`TetriServe`、`EDF-BestFit`、`SBP-ESP`、`SBP+c2` (`sbp-esp-cfg2`)、**`DitServe`**
- **构建版本**：`720da72`

## 1. 核心实验结论

1. **全 16 组速率点 SAR 全面领跑（含 `SBP+c2` 强化基线，Fig. 9）**：
   - **Poisson ($CV=1.0$)**：`DitServe` 在 $8 \to 36\text{ rpm}$ 取得 **100.0%, 96.0%, 91.0%, 86.0%, 84.0%, 80.0%, 82.0%, 81.0% SAR**（8 点均值 **87.50%**），超越 `SBP+c2` (81.75%)、`SBP-ESP` (76.62%)、`TetriServe` (74.88%)、`EDF-BestFit` (74.38%) 与 `xDiT` (38.50%)。
   - **Gamma ($CV=2.0$)**：`DitServe` 取得 **98.0%, 94.0%, 91.0%, 87.0%, 83.0%, 84.0%, 82.0%, 78.0% SAR**（8 点均值 **87.12%**），领先 `SBP+c2` (70.75%) 达 **+16.37 pp**，全面领先 `SBP-ESP` (73.12%)、`TetriServe` (70.88%)、`EDF-BestFit` (68.50%) 与 `xDiT` (29.25%)。
2. **重过载下图像 P95 尾延迟水平锁死，彻底消除跨模态 HoL 阻塞（Fig. 10）**：
   - 从 $8$ 到 $36\text{ req/min}$，`DitServe` 将 `SD3.5` 图像 P95 稳定锁在 **14.50–15.43 s** (Poisson) 与 **14.73–16.60 s** (Gamma)；而步边界策略 `SBP+c2` 仍因 4-step 轮次锁定在过载下升至 **18.64 s** (Poisson) / **299.00 s** (Gamma)，纯 SP 基线更是高达 **224.46–364.89 s**。
