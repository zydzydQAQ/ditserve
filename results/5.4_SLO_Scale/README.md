## 1. 核心实验结论

1. **全 10 个截止期区间全面领先（Fig. 11）**：
   - **Poisson ($CV=1.0$)**：`DitServe` 在 $\kappa \in \{1.0\times..2.0\times\}$ 取得 **66.0%, 91.0%, 96.0%, 96.0%, 99.0% SAR**（图像 **52%–100%**，视频 **80%–98%**；5 点均值 **89.6%**），超越 `SBP-ESP` (66.2%)、`EDF-BestFit` (65.2%)、`TetriServe` (63.2%) 与 `xDiT` (45.4%)。
   - **Gamma ($CV=2.0$)**：`DitServe` 取得 **56.0%, 88.0%, 94.0%, 96.0%, 98.0% SAR**（图像 **40%–100%**，视频 **72%–96%**；均值 **86.4%**），超越 `TetriServe` (64.6%)、`SBP-ESP` (62.8%)、`EDF-BestFit` (60.0%) 与 `xDiT` (31.4%)。
2. **极限零松弛 $\kappa = 1.0\times$ 与紧截止期 $\kappa = 1.25\times$ 救命能力**：
   - 在 $\kappa = 1.0\times$ 下，所有步级基线崩溃至 **1.0%–5.0% SAR**（图像 **0.0%**，**81.3%–97.9%** GPU 算力浪费在超时任务），仅开块抢占不开连续批处理 (`abl-no-cb`) 图像 SAR 亦为 `0.0%`（总 SAR 41%/36%）；`DitServe` 结合 `42.2–63.8 ms` 门铃、`shrink_decode` + `304.1 ms` 分块解码与 `advance_batch` 连续批处理，将图像 SAR 拉升至 **52.0% / 40.0%**，总 SAR 达 **66.0% (`13.2×`) / 56.0% (`11.2×`)**，每按时请求 GPU 成本降低 **10.8×–66.8×** 至 **115.94 / 138.71 GPU·s**，并在 $\kappa = 1.25\times$ 领先最强基线 **+27.0 / +28.0 pp**。
