## 1. 核心实验结论

1. **全模态比例全面领先（Fig. 7）**：
   - **Poisson ($CV=1.0$)**：`DitServe` 在 $v \in \{0.1..0.9\}$ 上取得 **97.0%, 100.0%, 96.0%, 87.0%, 77.0% SAR**（5 点均值 **91.4%**），全面超越 `SBP-ESP` (82.4%)、`TetriServe` (80.6%)、`EDF-BestFit` (77.6%) 与 `xDiT` (58.8%)，在 $v=0.5$ 领先基线高达 **+16.0 pp**，在 $v=0.9$ 领先 `xDiT` **+54.0 pp**。
   - **Gamma ($CV=2.0$)**：`DitServe` 取得 **100.0%, 99.0%, 94.0%, 83.0%, 73.0% SAR**（均值 **89.8%**），领先 `SBP-ESP` (78.0%)、`TetriServe` (77.0%)、`EDF-BestFit` (70.4%) 与 `xDiT` (47.2%) 达 **+7.0 ~ +20.0 pp**，图像 SAR 全程保持 **98.0%–100.0%**。
2. **均衡锚点 ($v=0.5, R=12\text{ rpm}, \kappa=1.5\times$) 归一化延迟 CDF（Fig. 8）**：
   - `DitServe` 在 $1.0\times$ SLO 内按时完成 **96.0% (Poisson) / 94.0% (Gamma)** 请求（图像 **100.0% / 98.0%**，视频 **92.0% / 90.0%**）。
   - 归一化延迟 `Latency/SLO` P50 / P90 / P95 控制在 **0.66× / 0.89× / 0.95×** (Poisson) 与 **0.68× / 0.95× / 1.16×** (Gamma)，而基线 P95 高达 `1.23×/1.31×` (`EDF-BestFit`)、`3.12×/6.04×` (`TetriServe`)、`5.52×/6.66×` (`xDiT`) 及 `4.72×/66.43×` (`SBP-ESP`)；图像 P95 压低至 **14.90 / 15.47 s**（基线 `15.55–241.60 s`），视频 P50 降至 **89.2 / 91.5 s**（基线 `127.1–304.5 s`）。
