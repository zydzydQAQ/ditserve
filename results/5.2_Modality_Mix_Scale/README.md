- **对比策略（6 策略）**：`xDiT`、`TetriServe`、`EDF-BestFit`、`SBP-ESP`、`SBP+c2` (`sbp-esp-cfg2`)、**`DitServe`**

## 1. 核心实验结论

1. **全 10 个模态混比点全面领先（含解锁 CFG2 的强化基线 `SBP+c2`，Fig. 7）**：
   - **Poisson ($CV=1.0$)**：`DitServe` 在 $v \in \{0.1..0.9\}$ 上取得 **99.0%, 100.0%, 96.0%, 86.0%, 75.0% SAR**（5 点均值 **91.2%**，Pooled 图像 SAR **99.6%**），超越强化基线 `SBP+c2` (86.6%)、`SBP-ESP` (82.4%)、`TetriServe` (80.6%)、`EDF-BestFit` (77.6%) 与 `xDiT` (58.8%)。
   - **Gamma ($CV=2.0$)**：`DitServe` 取得 **100.0%, 99.0%, 94.0%, 86.0%, 73.0% SAR**（5 点均值 **90.4%**，Pooled 图像 SAR **99.6%**），领先 `SBP+c2` (79.8%) 达 **+10.6 pp**，领先纯弹性 SP 基线 **+12.4 ~ +20.0 pp**。
2. **均衡锚点 ($v=0.5, R=12\text{ rpm}, \kappa=1.5\times$) 归一化延迟 CDF（Fig. 8）**：
   - `DitServe` 在 $1.0\times$ SLO 内按时完成 **96.0% (Poisson) / 94.0% (Gamma)** 请求（双分布图像 SAR 均达 **100.0%**，视频 **92.0% / 88.0%**），而 `SBP+c2` 为 `90.0% / 82.0%`。
   - 归一化延迟 `Latency/SLO` P50 / P90 / P95 控制在 **0.65× / 0.93× / 1.00×** (Poisson) 与 **0.66× / 0.97× / 1.94×** (Gamma)；图像 P95 压低至 **14.59 / 15.07 s**。
