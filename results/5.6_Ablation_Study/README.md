## 1. 历史锚点补充归因（$\lambda=13.2\text{ rpm}, v=0.5, \kappa=1.5\times$，`720da72`）

1. **三层累加阶梯与紧截止期连续批处理收益（`720da72` 同步实测）**：
   - `edf-cfg2`（仅静态 CFG2 基准）：**74.0% / 64.0% SAR**（图像 58% / 46%，视频 90% / 82%）。
   - `+ L3 亚步抢占与解码收缩` (`block-cfg2`)：提升 **+13.0 / +14.0 pp** 至 **87.0% / 78.0% SAR**。
   - `+ L1/L2 支配剪枝与 Pair-Fit 伙伴放置` (`abl-no-cb`，`720da72` 实测)：**94.0% / 93.0% SAR**（图像 100.0% / 100.0%，视频 88.0% / 86.0%，图像 P95 15.43 / 15.63 s）。
   - `+ L3 连续批处理与 cu_seqlens 打包` (**`DitServe`**)：Poisson 达 **94.0% SAR**（图像 **98.0%**、视频 **90.0%**，图像 P95 **15.29 s**），Gamma 达 **92.0% SAR**（图像 P95 **14.66 s**）；在极限紧截止期 $\kappa=1.0\times$ 下，连续批处理带来 **+28.0 / +24.0 pp** 总 SAR 跃升（`41.0% -> 69.0%` Poisson，`36.0% -> 60.0%` Gamma，图像 SAR 从 `0.0%` 拉升至 **`54.0% / 44.0%`**）。
2. **单因素剥离验证每层不可或缺（Leave-One-Out，`720da72` 全同步实测）**：
   - 去掉 L3 亚步抢占 (`abl-no-block`)：SAR 跌至 **84.0% / 85.0%**。
   - 去掉 L2 Pair-Fit 伙伴对齐 (`abl-first-fit`)：SAR 跌至 **82.0% / 75.0%**。
   - 去掉 L1/L2 形态剪枝 (`abl-no-prune`)：SAR 跌至 **82.0% / 86.0%**。
   - 去掉 L3 连续批处理 (`abl-no-cb`)：SAR 为 **94.0% / 93.0%**。
3. **外部基线解锁 `+CFG2` 因子化归因（Factorized `+CFG2` External Baselines）**：
   - 即便向外部调度器开放 `CFG2`，`edf-bestfit-cfg2`（**79.0% / 65.0%**）、`tetriserve-cfg2`（**83.0% / 72.0%**）与 `sbp-esp-cfg2`（**85.0% / 76.0%**）仍显著落后 **`DitServe`（94.0% / 92.0%）** 达 **+9.0–+15.0 pp**（Poisson）与 **+16.0–+27.0 pp**（Gamma $CV=2.0$）。
4. **L1 三参数 SVD 代价模型与双层数值门禁**：
   - 3 参数模型 $\kappa(J) \in [68.3, 75.4]$ 留出误差仅 **7.03%–12.78%**、形态排序遗憾 **0.0%**；Tier-1 块级续跑 **624/624 SHA256** 100% 逐位一致。
