## 1. 核心实验结论

1. **三层累加阶梯单调递进（Staircase，`edf-cfg2` $\to$ `block-cfg2` $\to$ `abl-no-cb` $\to$ `DitServe`）**：
   - `edf-cfg2`（仅静态 CFG2 基准）：**74.0% / 64.0% SAR**（图像 58% / 46%，视频 90% / 82%）。
   - `+ L3 亚步抢占与解码收缩` (`block-cfg2`)：提升 **+13.0 / +14.0 pp** 至 **87.0% / 78.0% SAR**。
   - `+ L1/L2 支配剪枝与 Pair-Fit 伙伴放置` (`abl-no-cb`)：提升至 **92.0% / 93.0% SAR**（图像 98% / 100%，Goodput `0.0966 / 0.0976 req/s`）。
   - `+ L3 连续批处理与 cu_seqlens 打包` (**`DitServe`**)：达到全场最高 **94.0% / 94.0% SAR**（**+2.0 / +1.0 pp**；图像 **100.0% / 100.0%**，视频 **88.0% / 88.0%**，图像 P95 **14.75 / 14.98 s**；在极限紧截止期 $\kappa=1.0\times$ 下更带来 **+25.0 / +20.0 pp** 总 SAR 跃升）。
2. **单因素剥离验证每层不可或缺（Leave-One-Out）**：
   - 去掉 L3 亚步抢占 (`abl-no-block`)：SAR 跌至 **80.0% / 80.0%**（图像跌至 76% / 70%）。
   - 去掉 L2 Pair-Fit 伙伴对齐 (`abl-first-fit`)：SAR 跌至 **82.0% / 76.0%**（图像跌至 **72.0% / 66.0%**，图像 P95 暴涨至 **67.3 / 142.9 s**，归一化 P99 达 **4.49× / 21.19×**）。
   - 去掉 L1/L2 形态剪枝 (`abl-no-prune`)：SAR 跌至 **84.0% / 86.0%**（视频跌至 **72.0% / 72.0%**，Busy GPU-s 暴涨 **+40.3%–44.8%** 至 **9,661 / 9,264 GPU·s**，P95 恶化至 **852.3 / 875.3 s**）。
3. **L1 三参数 SVD 代价模型与双层数值门禁**：
   - 3 参数模型 $\kappa(J) \in [68.3, 75.4]$ 留出误差仅 **7.03%–12.78%**、形态排序遗憾 **0.0%**（4 参数过拟合误差达 `21.33%–29.24%`）。
   - Tier-1 块级续跑 **624/624 SHA256** 100% 逐位一致，xDiT 速度对齐 `1.000×`，修复 TetriServe SD3.5 跨 SP RMSE 从 `0.1762` 降至 **`7.97×10^-5`**。
