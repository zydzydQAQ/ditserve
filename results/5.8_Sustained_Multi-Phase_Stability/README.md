# §5.8 Sustained Multi-Phase Stability (500-Request 5-Phase Soak)

- **对应论文小节**：`body/05-evaluation.tex` — `\subsection{Sustained Multi-Phase Stability}`
- **固定参数**：8× A100-PCIE-40GB，单次连续无重启 **500 请求**非平稳五阶段潮汐负载（$\kappa = 1.5\times$, `seed=301`），对比 `TetriServe`、`SBP+c2` (`sbp-esp-cfg2`) 与 **`DitServe`**
- **五阶段协议（`P1..P5`）**：
  - `P1` (`0..99`, 100 reqs)：`10 rpm`, $v=0.5$, Poisson ($CV=1.0$) — 稳态基准
  - `P2` (`100..219`, 120 reqs)：`28 rpm` ($3.71\times R_0$), $v=0.5$, Gamma ($CV=2.0$) — 突发过载风暴
  - `P3` (`220..319`, 100 reqs)：`14 rpm`, $v=0.2$, Poisson ($CV=1.0$) — 风暴后图像潮汐恢复
  - `P4` (`320..399`, 80 reqs)：`12 rpm`, $v=0.7$, Gamma ($CV=2.0$) — 重视频突发潮汐
  - `P5` (`400..499`, 100 reqs)：`10 rpm`, $v=0.5$, Poisson ($CV=1.0$) — 长程恢复与首尾对照
- **构建版本**：`720da72`

---

## 1. 核心实验结论

1. **500 请求全周期 SLA 大幅领先**：`DitServe` 全程取得 **85.40% Total SAR**（图像 **98.11%**，视频 **71.19%**，图像 P95 **18.61 s**），全面超越强化基线 `SBP+c2`（**71.60%**，图像 79.92% / 视频 62.29%）与 `TetriServe`（**66.60%**，图像 71.59% / 视频 61.02%）。
2. **风暴后极速消峰恢复（`P2 -> P3` & `P5` vs `P1`）**：在经历 `P2` 28 rpm Gamma 突发风暴后，`DitServe` 进入 `P3` 时的积压请求仅 **57** 个，`P3` 整体达成 **97.0% SAR**（前 25 请求 **92.0%**，图像 P95 **20.14 s**）；至末段 `P5`（与 `P1` 同分布参数），`DitServe` 取得 **92.0% SAR**（相对 `P1` `+1.0 pp`），证明长程无队列残留退化。
3. **HBM / `/dev/shm` / Host RSS 零漂移长稳运行**：全程 `0 OOM`，`DitServe` 稳态 HBM 均值斜率 **`+1166.24 MB/hr`**、`/dev/shm` 斜率 **`-3.49 MB/hr`**（结束残留 `0.0 MB`）、Host RSS 斜率 **`+3584.16 MB/hr`**，验证 `PinnedSlabPool`、块续跑状态机与 `/dev/shm` IPC 传输零内存泄漏。
